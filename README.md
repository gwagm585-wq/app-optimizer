# 총괄생산계획 최적화 (Aggregate Production Planning)

월별 수요 예측과 비용·생산 조건을 넣으면, 총비용이 최소가 되는 **월별 인원·생산·재고·외주·잔업 계획**을 계산하고 결과를 해석해 주는 웹 도구입니다.

**바로 사용해 보기 → https://gwagm585-wq.github.io/app-optimizer/**

> 스마트제조 과목(2026년 1학기) 과제로 제작. 설치 없이 브라우저에서 동작하는 단일 HTML 파일입니다.

## 모델

- **결정변수(월별)**: 종업원 수 W, 고용 H, 해고 L, 생산량 P, 재고 I, 부재고 S, 외주량 C, 잔업시간 O
- **목적함수**: 노동비 + 잔업비 + 고용·해고비 + 재료비 + 재고유지비 + 부재고비 + 외주비 최소화
- **제약**: 인원 수지(W<sub>t</sub> = W<sub>t-1</sub> + H<sub>t</sub> − L<sub>t</sub>), 생산능력(정규시간 + 잔업), 재고 수지(부재고 포함), 잔업 한도, 최종 재고 하한, 최종 부재고 0
- **정수 조건**: 인원(W·H·L)과 수량(P·I·S·C)은 정수, 잔업시간은 연속 (불량률을 반영할 때는 수량이 기대값이므로 인원만 정수)
- **품질·설비 연계(선택)**: 생산량 × 양품률만 재고로 들어가고, 생산 1개당 비용에 불량률 × 폐기비를 더하며, 설비 가용률을 생산능력에 곱함. 양품률은 SPC 대시보드의 공정능력 지수(Pp·Ppk)에서 계산

## 화면 구성

| 페이지 | 하는 일 |
|---|---|
| **01 입력 데이터** | 월별 수요 예측, 비용·생산 조건, 품질·설비(SPC 공정능력) 상태, 해법 옵션 입력 |
| **02 계획 최적화** | 비용 최소 생산계획(정수계획), 결과 해석, 전략 비교, 비용·인력 분석, 품질 연계(SPC) |
| **03 수요 변동 시뮬레이션** | 수요 불확실성 아래 최적 안전재고 수준 결정(몬테카를로), 민감도 분석 |

02·03 상단에는 결과를 계산한 입력 조건이 요약되고, 입력을 바꾸면 다시 실행하라는 표시가 뜹니다. 화면 글꼴은 공정 관제(HMI/MES) 화면처럼 라벨·지표 숫자에 DIN 계열 컨덴스드 글꼴(Barlow Condensed)을, 표·입력값에 고정폭 글꼴(IBM Plex Mono)을 썼습니다.

## 주요 기능

| 구분 | 내용 |
|---|---|
| 최적화 | 2단계 심플렉스(LP)와 분지한계법(정수계획)을 외부 라이브러리 없이 JavaScript로 구현(브라우저에서 바로 동작). 정수해/LP 완화해 전환 가능 |
| 전략 비교 | 같은 조건에서 평준화(Level: 인원 고정)·추종(Chase: 재고 없이 인원으로 수요 추종) 전략을 제약으로 고정해 다시 풀고, 최적 계획과 총비용·인력 변동을 비교 |
| 안전재고 시뮬레이션 | 03 페이지. 안전재고 수준별로 계획을 다시 최적화하고 수요 변동 시나리오(몬테카를로)로 기대 총비용·P90 비용·납기 위험을 비교해 최적 안전재고를 찾음. 지연 비용 × 수요 변동성 민감도 분석 포함 |
| 품질 연계 (SPC) | 공정능력(Pp·Ppk) → 예상 불량률 → 생산계획 비용 연결. 품질 손실 비용, 목표 Ppk 달성 시 절감액(개선 투자 한도), 품질 손실이 계획 비용의 1%를 넘는 Ppk 관리 기준선, 공정능력 수준별 인원·외주 변화를 계산 |
| 결과 해석 | 인력 운용 방식(평준화형/추종형), 재고 비축·소진 구간, 부족분 대응 수단, 단가 비교, 비용 구조, LP 대비 정수해 비용 차이를 자동 요약 |
| 지표 | 총비용, 납기 내 충족률(부재고로 지연된 수량 제외), 최종 재고 목표, 인력 변동 횟수 |
| 시각화 | 수요 vs 생산, 재고·부재고 추이, 월별 비용 구성, 비용 구성비, 누적 비용, 인력 변동, 잔업 시간 |
| 시나리오 비교 | 결과를 저장한 뒤 조건을 바꿔 다시 풀면 두 계획의 비용·생산·재고·인력 변동을 나란히 비교 |

## 기본 예제 결과 (수요 1,600~3,800개/월, 6개월)

- LP 완화해 422,275천원 → **정수해 422,660천원** (+0.09%). LP 해의 64.6명 같은 소수 인원은 실행할 수 없으므로 정수해로 계획합니다.
- 1월에 15명을 해고해 65명 수준을 유지하고, 1월에 쌓은 재고로 2~4월 수요 피크를 메우는 **평준화형 계획**입니다.
- 같은 조건에서 **추종(Chase) 전략은 473,040천원**으로 최적 계획보다 50,380천원(11.9%) 비쌉니다. 인원을 68~95명 사이로 계속 바꾸느라 고용·해고가 52명 발생하기 때문입니다. 이 예제에서는 평준화 전략이 최적 계획과 같은 비용입니다.
- 4월 피크의 부족분은 부재고 220개(5월 해소)와 외주 20개로 대응하고, 잔업은 쓰지 않습니다. 잔업으로 1개 더 만드는 비용(34)이 외주(30)보다 비싸기 때문입니다.
- 정수해 결과는 외부 솔버(CBC)로 같은 모델을 풀어 일치하는 것을 확인했습니다.

## 품질 연계: SPC 결과로 생산계획 세우기 (02 계획 최적화 → '품질 연계' 탭)

[SPC 대시보드](https://gwagm585-wq.github.io/spc/)가 "지금 공정이 규격을 얼마나 잘 지키나(Pp·Ppk)"를 진단한다면, 이 탭은 그 결과가 **생산계획 비용에 얼마나 영향을 주는지**로 번역합니다.

- **불량률 계산**: 정규분포 가정에서 불량률 = Φ(−3·Ppk) + Φ(−(6·Pp − 3·Ppk)). SPC 대시보드의 예상 불량률과 같은 방식입니다.
- **계획 반영**: 불량이 있으면 양품을 맞추려고 더 많이 만들어야 하므로 인력·재료·외주·폐기비가 늘어납니다. 같은 수요·비용 조건에서 공정능력만 바꿔 계획을 다시 최적화해 비교합니다(Pp/Ppk 비율 = 중심 치우침은 고정하고 산포만 변경).
- **검증**: 양품률·가용률을 넣은 모델의 결과를 외부 솔버(CBC)로 같은 모델을 풀어 일치를 확인했습니다.

**SPC 대시보드 기본 예제 값(Pp 1.22, Ppk 1.138)을 넣은 결과**

| 항목 | 결과 |
|---|---|
| 예상 불량률 | 367 ppm (양품률 99.963%) |
| 품질 손실 비용 (6개월) | +204천원 (계획 비용의 0.05%) |
| Ppk 1.33 달성 시 절감 | 188천원 → 생산계획 관점의 공정 개선 투자 한도(하한값) |
| 관리 기준선 | Ppk 약 0.80 미만이면 품질 손실이 계획 비용의 1% 초과 |
| Ppk 0.50일 때 | 불량 11%, 생산 +1,080개, 최대 인원 65 → 69명, 계획 비용 +11.6% |

- 해석: 현재 공정 수준에서는 품질 손실이 계획 비용의 0.05%라, **비용 절감의 우선순위는 품질보다 인력·재고 계획**입니다. 다만 Ppk가 0.8 아래로 떨어지면 비용이 급격히 늘어나므로, SPC 대시보드에서 Ppk를 모니터링할 때 이 값을 경보 기준으로 쓸 수 있습니다.
- 투자 한도는 생산계획 비용만 따진 값이라, 반품·클레임 같은 외부 실패비용을 더하면 실제 개선 가치는 이보다 큽니다.

## 수요 변동 시뮬레이션: 안전재고를 얼마나 둘까 (03 페이지)

02 계획 최적화는 예측 수요가 정확하다고 가정합니다. 03 수요 변동 시뮬레이션은 **수요가 예측과 다를 수 있을 때 재고 여유(안전재고)를 얼마나 두는 계획이 기대 총비용이 가장 낮은지**를 몬테카를로 시뮬레이션으로 찾습니다.

1. 안전재고를 다음 달 수요의 0~50%로 바꿔가며 02 계획 최적화 모델을 다시 풀어 계획 11개를 만듭니다 (매달 말 순재고 ≥ 다음 달 수요 × x%).
2. 각 계획의 인원·생산·외주·잔업은 고정하고, 실제 수요 = 예측 × (1+ε), ε ~ N(0, 변동성²)로 수백~수천 개 시나리오를 만들어 **모든 계획에 같은 시나리오**를 적용합니다.
3. 계획보다 부족해지면 남은 잔업 한도 안에서 추가 생산, 그래도 모자라면 부재고. 기간 말 남은 부재고·최종재고 부족분은 긴급 외주 단가로 채우고, 목표 초과 재고는 정규 생산 단가만큼 차감합니다.
4. 안전재고 수준별 기대 총비용·나쁜 경우(P90) 비용·납기 내 충족률·지연 발생 확률을 비교하고, **지연 비용 × 수요 변동성**에 따라 최적 안전재고가 어떻게 바뀌는지 민감도 표로 보여줍니다.
5. **슬라이더로 안전재고를 0~50% 사이에서 1% 단위로 직접 바꿔보면**, 그 수준의 계획을 즉시 다시 최적화·시뮬레이션해 지표와 월말 순재고 범위를 보여주고, 최적 수준과의 기대비용 차이를 같은 시나리오로 짝지어 **95% 신뢰구간**과 함께 표시합니다. 최적과 통계적으로 구분되지 않는 수준은 '최적 범위'로 묶어 보여줘, 한 점의 값을 과도하게 정밀하게 해석하지 않도록 했습니다.

**검증**: 변동성 0%에서 안전재고 0% 계획의 기대 총비용이 02 계획 최적화의 계획 비용(422,660)과 정확히 일치합니다.

**기본 예제 결과 (변동성 10%, 1,000회)**

| 안전재고 | 계획 비용 | 기대 총비용 | 나쁜 경우 (P90) | 납기 내 충족률 | 지연 발생 확률 |
|---|---|---|---|---|---|
| 0% | 422,660 | **426,540** | 452,868 | 98.2% | 65% |
| 10% | 431,660 | 428,616 | 451,316 | 99.4% | 28% |
| 30% | 447,020 | 430,744 | 449,432 | 99.8% | 10% |

- 기본 부재고비(지연 1개·1개월에 5천원)에서는 안전재고를 두지 않는 쪽이 기대비용이 가장 낮습니다. 지연이 싸기 때문에 잔업과 짧은 지연으로 대응하는 편이 경제적입니다.
- 다만 안전재고 10%만 둬도 기대비용은 0.5%(2,076천원) 늘지만 지연 발생 확률이 65% → 28%로 떨어지고, 나쁜 경우(P90) 비용은 오히려 줄어듭니다.
- 핵심 변수는 **지연 비용**입니다. 고객 신뢰 손실·위약금까지 포함해 지연 비용을 개당 월 20천원으로 보면, 변동성 10%에서 최적 안전재고는 **15~20% 범위**로 바뀝니다(두 수준의 기대비용 차이는 39 ± 110천원으로 통계적으로 구분되지 않음).
- 기본값에서 안전재고 0%가 5%보다 싸다는 결과는 차이 1,704 ± 118천원(95% 신뢰구간)으로 시뮬레이션 오차보다 충분히 큽니다.

| 부재고비 \ 변동성 | 5% | 10% | 20% | 30% |
|---|---|---|---|---|
| 5 (기본값) | 0% | 0% | 0% | 0% |
| 10 | 0% | 0% | 35% | 50% 이상 |
| 20 | 5% | 20% | 50% 이상 | 50% 이상 |
| 40 | 5% | 25% | 50% 이상 | 50% 이상 |

## 한계

- 품질 연계는 불량을 전량 폐기한다고 가정하며(재작업 없음), 불량률이 기간 내내 일정하다고 봅니다. 공정능력→불량률 변환은 정규분포 가정에 의존합니다.
- 최적화(02 페이지)는 수요를 확정값으로 가정합니다. 수요 불확실성의 영향은 03 페이지 시뮬레이션으로 사후 평가하며, 불확실성을 직접 반영한 최적화(확률계획)는 하지 않습니다.
- 시뮬레이션의 수요 오차는 월별 독립 정규분포로 가정합니다(실제로는 월 간 상관이나 비대칭 오차가 있을 수 있음).
- 안전재고는 '다음 달 수요의 x%'라는 단순 규칙이며, 실행 단계의 대응도 '남은 잔업으로 보충 후 부재고'라는 고정 규칙입니다. 매달 계획을 다시 세우는 롤링 방식은 반영하지 않습니다.
- 단일 제품·단일 공정의 총괄 수준 계획으로, 품목별 일정계획은 다루지 않습니다.
- 정수해는 계산 시간 제한(4초) 안에서 구하며, 기간이 매우 길면 최적성이 보장되지 않을 수 있습니다(화면에 표시).

## 개선 이력

- 2026.05 — 스마트제조 과목 과제로 최초 제작(LP)
- 2026.11 — 분지한계법 정수해 추가, 평준화·추종 전략 비교 추가, 안전재고 결정용 몬테카를로 시뮬레이션 페이지 추가, SPC 공정능력(불량률)·설비 가용률을 생산계획에 연계, 결과 해석 자동 요약 추가, 수요 충족률 지표를 납기 내 충족률로 수정, 모바일 화면 대응
